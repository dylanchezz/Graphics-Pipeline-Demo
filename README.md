# Interactive Graphics Pipeline Simulator
This is a multimedia application developed using HTML5 Canvas, CSS, and JavaScript.

## Description

The application demonstrates the three main stages of the graphics pipeline:

1. Application Stage
   - Handles mouse input and updates animation speed.

2. Geometry Stage
   - Applies 3D rotation, world translation, and perspective projection.

3. Rasterization Stage
   - Sorts polygon faces by depth and draws them onto the HTML5 Canvas.

## Objects Used

The application contains two 3D objects:

- A rotating cube
- A rotating pyramid

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API
